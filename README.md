# bank-earnings-reports
Destination for bank earnings reports created by dmgerbino's AI agents.

Live site: https://dmgerbino.github.io/bank-earnings-reports/ (GitHub Pages, branch `main`, folder `/`).

## Layout

- `index.html` — home page listing every bank, newest release first. Generated; don't edit by hand.
- `reports.json` — the list the home page is built from (slug, bank, ticker, quarter, release date, headline).
- `<ticker>-<quarter>-<year>/` — one folder per report, e.g. `pnc-q3-2026/`:
  - `report.html` — the report exactly as the earnings-report skill made it (source).
  - `index.html` — the published page: the report plus a back link, the videos and the infographic. Generated.
  - Media from infographic-to-video-v2: `*-captioned.mp4`, `*-short-captioned.mp4`, `*-clean.mp4`, `*-short-clean.mp4`, `*.srt`, `*-mobile.png/.svg`, and `*-infographic.png/.svg`.
- `og.png` and `<slug>/og.png` — 1200x630 share cards (Open Graph and Twitter) for the home page and each bank. `<slug>/og.json` holds the bank card's figures. Generated by `scripts/og.py`.
- `data/prices/<TICKER>.csv` — daily closes for each card's 90-day price line; sources in `data/prices/SOURCES.md`.
- `templates/method-and-sources.html` — the fixed layout for every page's Method and sources section (modelled on PNC): one method paragraph, a bulleted list of named source links, then "Not investment advice." on its own line. The script fills it in; don't hand-write this section.
- `.nojekyll` — tells GitHub Pages to serve files as they are.

## Adding a new bank (what each scan does at the end)

1. Run the earnings-report skill, then infographic-to-video-v2, so you have the report HTML and a folder of media.
2. From the repo root, run:

   ```
   python3 scripts/publish.py add --slug ophc-q3-2026 \
     --report path/to/report.html \
     --media path/to/bank-folder --media path/to/bank-folder/video \
     --bank "OptimumBank Holdings" --ticker OPHC --quarter "Q3 2026" \
     --released 2026-11-12 \
     --headline "The report's one-line headline" \
     --method "One paragraph: basis of the figures (GAAP or adjusted, units), derived quarters, how growth rates and ratios were computed, consensus source and timing, peer data source, caveats. Data was read on Nov 13, 2026." \
     --source "OptimumBank Q3 2026 earnings release (GlobeNewswire, Nov 12, 2026)|https://..." \
     --source "Zacks earnings preview, pre-release (TradingView)|https://..." \
     --source "USCB Financial Q3 2026 release (8-K Ex 99.1)|https://..." \
     --exchange "NYSE American" \
     --net-income '$7.2M' --net-income-note '▲ 65.9% vs. Q3 2025' \
     --eps-label "Diluted EPS" --eps '$0.30' --eps-note 'Beat $0.27 consensus' \
     --prices path/to/OPHC.csv
   ```

   `--method` and at least one `--source "Label|URL"` are required unless the report already uses the template. Give every source the report cites, each with a plain-English label (bank, quarter, document, and where it was read if not the bank's own site). Keep caveats (stale estimates, secondary copies, bank-level ratios) in the method paragraph. The script swaps them into `templates/method-and-sources.html` and puts that in place of the report's own Method and sources section, so every bank page matches.

   The last five lines are the share card (see Share cards below). `--exchange`, `--net-income`, `--net-income-note` and `--prices` are required for a new bank.

   It copies the report and media into the bank's folder, renders the bank's share card (`og.png`), builds that folder's `index.html` with the Open Graph and Twitter tags, adds the bank to `reports.json`, rebuilds the home page, and stops if any file is over 50 MB. Running it again for the same slug replaces that bank's entry but keeps its first-published date.
3. Commit and push to `main`:

   ```
   git add -A && git commit -m "Add OPHC Q3 2026" && git push origin main
   ```

   Pages updates within a minute or two.

## Share cards

Every page carries `og:` and `twitter:` tags (summary_large_image) pointing at a 1200x630 PNG: the brand card `og.png` for the home page, and `<slug>/og.png` for each bank. The design was approved by David on Nov 14, 2026; keep to it.

A bank card shows the bank name, exchange and ticker, quarter and release date; a 90-day closing-price line ending on release day, green if the stock rose over the window and red if it fell, with the % change; net income with its change vs the year-ago quarter; an EPS-vs-consensus line only when a real pre-release consensus exists; and "Published <date>" from `reports.json` `added`. When a bank is added again under the same slug (a redone report), `add` keeps the first `added` date, sets `updated`, and the card reads "Updated <date>" with a smaller "First published <date>".

Rules for the card's figures, all checked against the bank's own release:

- `--exchange`: as the release writes it, e.g. "(NYSE: PNC)" gives `NYSE`; "(NYSE American: OPHC)" gives `NYSE American`; "(NASDAQ: WSBF)" gives `Nasdaq`.
- `--net-income` and `--net-income-note`: GAAP net income for the quarter and its change vs the same quarter a year earlier, written `▲ 15.1% vs. Q3 2025` or `▼ 22.1% vs. Q3 2025`. When either quarter is a loss, give the year-ago figure instead: `▲ from −$2.7M in Q3 2025`. Use `--net-income-label "Net income to common"` when that is the line the report uses.
- `--eps`, `--eps-label`, `--eps-note`: only when a current pre-release consensus exists for the quarter, on the same basis (`Adjusted EPS` vs an adjusted consensus, `Diluted EPS` vs a GAAP one). Leave them out when there is none or it looks stale; `--no-eps` drops a line given earlier.
- `--prices`: a CSV with header `date,close` covering at least the 90 calendar days to the release date. Shell downloads from most price sites are blocked here, so read the closes from Yahoo Finance's historical prices page (or another reliable public source), save them as the CSV, and add a row to `data/prices/SOURCES.md`.

Keep the bottom of every card empty. X lays the site domain over the bottom of a large-image card, so `SAFE_BOTTOM` in `scripts/og.py` (96 px of the 630) stays plain background: no text, no chart. The generator refuses to render a card that puts anything there. When you change the card layout, bump `CARD_VERSION` in `scripts/og.py`; it goes into the `?v=` on every `og:image`, so X and other sites fetch the new image instead of a cached one.

Rendering needs `cairosvg` (`python3 -m pip install cairosvg`) and the Inter font. `python3 scripts/publish.py og` re-renders every card and rebuilds the pages; `--slug <slug>` re-renders one. `build` renders any card that is missing. Social sites cache images, so the tags add `?v=<date>` to the image URL; it changes when a report is updated or the card version changes.

To fix only the Method and sources section of a bank already on the site: `python3 scripts/publish.py method --slug ophc-q3-2026 --method "..." --source "Label|URL" ...`, then commit and push.

To rebuild every page from what's already in the repo (after changing the script, say): `python3 scripts/publish.py build`.

The script needs only Python 3, no packages and no build step.
